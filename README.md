# q2-subsonic

A Subsonic client for the **Shanling Q2** running [Q2 Pod](https://github.com/DiamondBond/q2-pod). Pick playlists, albums, artists and songs on the Q2, and it syncs them to the card over Wi-Fi, or streams a song straight from your server. It needs a Q2 Pod build that supports card apps, and a Subsonic or OpenSubsonic server (Navidrome, for one) reachable over HTTPS, or over plain HTTP on your home network.

## Install

**Over Wi-Fi:** on the Q2, open **System settings → App Store** and press **Subsonic**.

**By hand:**

1. Download `q2-subsonic-*.zip` from the latest release.
2. Power the Q2 off, then put its microSD card in your computer.
3. Unzip the file to the card's root, so the card has `.subsonic/q2-subsonic`, `.subsonic/run`, `.subsonic/q2app` and its icons `.subsonic/icon.png` and `.subsonic/icon-40.png`. The leading dot hides the folder on macOS (Cmd+Shift+. in Finder shows it) and Linux.
4. Eject the card, put it back in the Q2 and power it on.

**Subsonic** then has a row in **Streaming**.

## Sign in

1. Open **Streaming → Subsonic**. While signed out, the only row is **Sign In from Your Phone**.
2. Press it. The Q2 shows a QR code, and under it the page's address and a PIN. Scan the code with your phone on the same Wi-Fi and the form opens straight away; if you type the address instead, the page asks for the PIN first. Fill in the server address, user name and password. A server address pasted with its API path (`/rest/…`) is cut back to the server's. **At Home** is optional: see [Home address](#home-address). (On Q2 Pod without the `signin` extension, press the row a second time to open the QR page.)
3. The Q2 follows along: **Continue on Your Phone**, **Signing In…**, then **Signed In** and the list opens. If it fails, the phone says why under the field it concerns, and the Q2 and the row say so too. The next sign-in fills in the last server you signed in to.

Things to know:

- The sign-in page runs only after you press **Sign In from Your Phone**, and stops when you are signed in, when you leave the QR page, or after 10 minutes. The screen turning off doesn't stop it. Until you press it, the app opens no port.
- A server only on Tailscale (a `*.ts.net` name or a `100.64.0.0/10` address) can't be reached from the Q2: use its public address.
- The password crosses your local Wi-Fi unencrypted, once, from the phone to the Q2. Do it on a network you trust.
- The server must be `https://`, unless it is on your home network: `http://` works only for a private address (`10.x`, `172.16` to `172.31`, `192.168.x`, typed as the address, not a name) and is refused anywhere else. Certificates are verified.
- The password is stored on the card, in `.subsonic/credentials`. If your server offers OpenSubsonic API keys (`apiKeyAuthentication`), enter a key from its settings as the password instead: then only the key is stored. exFAT has no file permissions, so anyone with the card can read it. **Make a server user just for the Q2, not an admin.** If the card is lost, delete that user on the server and the card is worthless.
- **Settings → Account** shows the server, the home address when there is one, and the user.
- **Settings → Account → Sign Out** removes the stored login and empties the Stream Cache, but for a list that is still playing. Your synced music stays on the card.

### Home address

If your server is at home, fill in **At Home** on the sign-in page with its address on your home network, such as `http://192.168.1.20:4533` (`http://` is added when you type no scheme). Whenever the Q2's Wi-Fi is on that address's subnet (from the Q2's own address and mask), the app asks the server there first; anywhere else it uses the server address above. If the home address doesn't answer, the request goes to the server address, and so does every request for the next minute. It must be a private address (`10.x`, `172.16` to `172.31`, `192.168.x`); anything else is refused under the field. It is kept in `.subsonic/settings.json` with the other settings, not with the login, and a sign-in with the field empty clears it.

## Use

On Q2 Pod 1.7.3 or later the first page is tabs: **Home** (everything, as one list, so the wheel reaches it all), **Discover**, **Playlists**, **Albums** and **Artists**. Swipe left or right to move between them; the title says which one you are on, such as Albums 4/5. **Search** is the magnifying glass at the right of the title bar on every tab (under **Theme: Classic**, which has no title bar, the first row of each tab). On older Q2 Pod the first page is one list: **Sync Entire Library**, **Sync**, **On This Q2**, **Playlists**, **Albums**, **Artists**, **Discover**, **Search** and **Settings**. A list you opened is kept for a minute, so a change made on the server can take that long to show.

**Long lists:** on Q2 Pod 1.7.3 or later a list shows 480 rows at a time, with **Next page** and **Previous page** at its ends, and **Artists** opens on the server's index (the letters A to Z, each with its count) when you have more than 60 artists. On Q2 Pod 1.7.6 or later **Albums** has a **Sort** row: **Recently Added**, **By Artist** or **By Year**, newest first; a server other than Navidrome may leave albums without a year out of By Year. Albums has no A to Z index of its own: use Artists, By Artist or Search. On older Q2 Pod a long list ends in **More…** after 500 rows, Artists is one list and Albums is A to Z only.

**Covers:** on Q2 Pod 1.7.3 or later the lists that are all albums or all playlists show each one's cover beside its row: **Albums** in every order, **Playlists**, Discover's album lists and a genre's albums. A list opens at once and its covers appear a few seconds later; in a long list, covers past the first rows appear the next time you open it, and they come slower while a sync runs. A server that sends no cover for an item, sends WebP, or ignores the size asked for (64 px) leaves the row plain. Covers are kept in the Q2's memory, never on the card, and are gone when the app stops. Every other page keeps the theme's plain rows: an artist's page (its albums too), an album's or playlist's songs, On This Q2, Artists, Search and Starred have none. On older Q2 Pod the lists look as before.

**Choosing what to sync:** hold **Play/Pause** on a playlist, album, artist or song to toggle it in Sync, or open it and press **Add to Sync** / **Remove from Sync**. The Q2 answers `Added to Sync · N songs`, `Removed from Sync` or, for a song already covered by something bigger, `Included via <name>`. **On This Q2** lists what you picked, with its status and size on the card; hold Play/Pause there to take one out.

**Quality** is per item, with a default in **Settings → Default Quality**: **Original** (the default), **MP3 320** or **MP3 128**. Change it with the **Quality** row inside a chosen item; Entire Library's and a single song's are in **On This Q2**. An original the Q2 can't play (WavPack, Musepack) syncs as MP3 320. AAC is not offered: Navidrome's AAC transcode can't carry tags.

**Syncing:** open **Sync**. It first checks the server (`Checking server…`, with a count such as `4500 of 10000 songs` when Sync Entire Library is on), then shows a preview, and nothing happens until you press **Start Sync**: songs to add (`+N`), to remove (`−N`), to replace (`Replace N`), playlists to update (`Update N playlists`), and `Needs X · Y free`. A song you deleted from the card is fetched again. If the card is too small it says so and offers no Start. Then it shows progress: percent, songs, time left, the current song, and **Pause**, **Resume** and **Cancel**. Leave the page and the sync carries on. If Wi-Fi drops or the Q2 restarts, it picks up where it was. Songs that fail are listed under **Failed Songs**, with **Retry Failed**.

**Discover** has **Shuffle All** (100 songs the server picks), **Recently Added**, **Recently Played**, **Most Played**, **Random Albums**, **Starred** and **Genres**. A genre lists its albums, with its own **Shuffle**. Recently Played and Most Played count what the server user has played, songs played from the app included (**Report Plays**, below). Random Albums stays the same until you open Discover again. Starred shows what that user starred on the server; songs given five hearts on the Q2 are starred there with the firmware's `ratings` extension (**Show in Library**, below).

**An artist's page** has **Play** (all its albums in order), **Shuffle**, **Radio** (an endless list of songs like the artist's, picked by the server) and **Top Songs**, above its albums. Play and Shuffle fetch the albums first, so music can start a little after the toast. Radio and Top Songs depend on the server: Navidrome has both, through Last.fm when that is set up. On a server without them they say `Not available on this server`. With the firmware's `artist` extension the page also says how many albums, singles and songs the artist has and their genre, and has **Singles & EPs** (singles and EPs, by the server's OpenSubsonic release types; a server without them lists every release under the albums), **Similar Artists** (from `getArtistInfo2`: artists on your server the server finds similar, through Last.fm on Navidrome) and **All Songs**, each only when it has something; Top Songs is left out when the server has none, and Top Songs and All Songs show each song's album and length. The page waits at most 5 seconds for Top Songs and similar artists.

**Playing:** press a song to play it and the rest of the list after it; search results, Starred and Top Songs work this way too. Songs already synced play from the card; the others stream. A song streams in its original format: FLAC and MP3 always, and other formats the Q2 plays too when the firmware has the `playlist` extension; without it they stream as MP3 320. **Settings → Streaming Quality** (Original, the default, MP3 320 or MP3 128) overrides this: anything but Original transcodes every streamed song to MP3. With the firmware's `playlist` extension, a song the server can't send (gone from it, or a format it can't convert) is skipped and the list plays on, and the main page says which; if the server can't be reached, or three songs in a row fail, the stream stops at that song.

**Stream Cache** (in **Settings**, 2 GB by default; needs the firmware's `playlist` extension): the songs you stream stay on the card, in `.subsonic/stream/`, hidden from the Q2's Library and playlists. A song streamed before starts at once and needs no Wi-Fi, and a list you started plays on offline as far as its songs are kept; opening a list still needs the server. Press the row to step through 512 MB, 1 GB, 2 GB, 4 GB, 8 GB and **Off**. A new size deletes nothing by itself: a smaller one, or Off, applies when the next song is streamed. When the cache is full the songs played longest ago go first; the list that is playing is never taken, and the cache gives way until 256 MB of the card are free (the list playing is fetched even with less). **Clear Cache** shows how much is kept, and a second press within 10 seconds empties it, but for the list that is playing; of a list you left, or paused for more than half an hour, only the songs around the one last played stay, until you play another list. A sync comes before the cache: the Sync page counts the cache's space as free, says `Takes 1.2 GB from the Stream Cache` when the sync needs it, and the sync then deletes the songs played longest ago. A kept song belongs to the account and the **Streaming Quality** it was fetched with, so another quality fetches it again and the old copy goes when its turn comes. **Sign Out** empties the cache in the same way. A song changed on the server under the same id plays from the kept copy until that is gone: Clear Cache fetches it fresh. With **Off**, without the `playlist` extension, and for a song whose server id is longer than 64 characters or holds other characters than letters, digits, `.`, `_` and `-`, streamed files are deleted as you go.

**Go to Album** and **Go to Artist** (hold in Now Playing, on Q2 Pod 1.6.0 or later) on a song you stream open that album's or artist's page in the app, where you can play it or add it to your sync. An artist who has no album of their own on the server, such as a guest or one track's artist on a compilation, shows `No albums`; a server that doesn't name the song's album or artist says so. A synced song opens the Q2's own Library pages, also when it plays inside a streamed list. On older Q2 Pod a streamed song has no Go to rows.

**Lyrics** (on a Q2 Muse whose lyrics page asks the app): when the Q2's lyrics page shows a song from your server, streamed or synced, that has no lyrics of its own (no `.lrc` beside it, no lyrics tag), the Q2 asks the app, which asks the server once: OpenSubsonic's `getLyricsBySongId` when the server offers `songLyrics` (Navidrome does), else `getLyrics` with the song's artist and title. What the server gives is saved beside the song, same name, `.lrc`: `[mm:ss.xx]` lines when it is timed, plain lines when not. The page fills in when the answer comes, and from then on the Q2 reads the file itself, with no request. A song the server has no lyrics for is noted in `.subsonic/lyrics-none.txt` and not asked about again for 30 days; a server with no lyrics call at all is asked once while the app runs. Nothing is fetched ahead of the page. The `.lrc` is deleted with its song (a sync removing it, the Stream Cache letting it go) and moves with it when a sync renames it.

**Storage** (on Q2 Pod with the firmware's `storage` extension): **System settings → Storage** on the Q2 shows the card's use, with the app's part as **Downloads** (the songs synced to `Subsonic/`) and **Stream Cache** (all of `.subsonic/`, the cache and covers with it). The app keeps `.subsonic/storage.tsv` for it, brought up to date every 30 seconds while the app runs and at once after a change, and takes the Q2's requests from `.subsonic/storage.out`. **Storage → Downloads** lists each item you chose to sync with its size: press one to open it in the app, hold Play/Pause to take it out of Sync (its songs go at the next Sync). Its **Limit** (No Limit by default, or 4, 8, 16, 32 or 64 GB, counted as 10^9 bytes as the app's sizes are) caps the synced songs: a sync that would take them past it says by how much and offers no Start. The Stream Cache already gives way to a sync first (above). Every item is one you picked; the app downloads nothing on its own yet.

**Report Plays** (in **Settings**, on by default): a song played from the app is reported to the server, which shows it as playing now and counts a play once the song has been on for half its length or 4 minutes (a song of 30 seconds or less is never counted). Play counts, Recently Played and Most Played, and a Last.fm or ListenBrainz account linked on the server follow what you hear on the Q2. A play that can't be sent waits, with up to 19 others, for the next song that counts; plays still waiting when the app stops are lost. The Q2 tells the app only which song plays, so a song paused early, or left for the Q2's own Library, still counts, and a song played twice in a row counts once. Songs played from the Q2's own Library are not reported. If the Q2 uploads its own scrobbles (`.scrobble.ini`) to the account the server forwards to, listens show twice there: turn one of the two off.

**Show in Library** (in **Settings**, Off by default; needs the firmware's `catalogue` extension): the server's songs and playlists appear in the Q2's own Library beside the card's, so Artists, Albums, Songs, Cover Flow and Playlists show your whole server. The Q2's **Settings → Library → Streaming Songs** switch (**Library → Local + Server** on older Q2 Pod) shows them; the app supplies them. With the firmware's `libsource` extension, Show in Library says On only while Streaming Songs is on too: turning Show in Library on while Streaming Songs is off asks to turn Streaming Songs on first, and while Streaming Songs is off the app pauses, asking the server nothing and keeping its files, so turning it on again goes on without a new first copy. Songs you synced appear once, as the card's. A press on a server song plays it as Subsonic's lists do: it streams, and a song already in the Stream Cache plays from the card. If the server is lost while a list started in the Library plays, the songs not on the card are taken out of it and the rest play on. What the app keeps:

- The first time, it asks for every song, 500 at a time (19 requests for 9,199 songs on Navidrome, a few seconds), then the playlists and stars, and writes `.subsonic/catalogue.tsv` for the firmware. There is no limit on the library's size, and the list is never held in the Q2's memory whole.
- Each time the app reaches the server again (when it starts, and after the server was out of reach) it asks whether the library changed (Navidrome's last scan and song count, or on other servers the folders' last change). When it did, the app asks for every song again once the Q2 is not syncing or playing from the app, or is charging. **Settings → Resync Library** does it at once. Playlists and stars are checked every time, a playlist asked for again only when its date changed.
- A song the server no longer has is kept in the list, greyed, while the Stream Cache has it, and leaves it otherwise; it comes back if the server has it again.
- Album covers for the Library: while no sync runs and the stream has no song to fetch (a list playing songs it already fetched, or the Stream Cache's, does not stop it), or while the Q2 charges, and the server answers, the app fetches each catalogue album's cover at 160 pixels (`getCoverArt`, two at a time, for at most 30 seconds a minute, through the same network slot syncs and streams take first) into `.subsonic/covers/<album id>.jpg`, and the Q2 shows it where it would show a card album's cover, the placeholder until then. A stopped round goes on from where it was at the next check. The folder holds at most 256 MB, counting each file as the card's whole cluster (about 8,000 albums on a card with 32 KB clusters, 2,000 with 128 KB), and no cover is written while the card has less than 1 GB free; covers of albums that leave the library are deleted, and an album the server has no cover for is not asked again. A server playlist's cover (Navidrome makes one from its albums' covers) is fetched the same way into `.subsonic/covers/pl-<playlist id>.jpg`, and again whenever the server gives it a new cover id, as Navidrome does when the playlist's songs change; one the server had none for is asked again then too. On the developer's Navidrome a cover is 3 to 6 KB and takes 50 to 350 ms. Once every album has its 160 px cover, the same rounds fetch each again at 512 pixels into `.subsonic/covers/512/`, for the Q2 Muse's Car Remote to send to a car's larger screen (the Q2 itself keeps drawing the 160 px ones); that folder has a 256 MB budget of its own, and the same 1 GB free-space rule.
- The Q2 says the server is offline only when it gets no answer at all. A wrong password or another error from the server shows under Resync Library instead.
- With the firmware's `ratings` extension too, hearts follow a song both ways, for streamed and synced songs alike: hearts given on the Q2 are sent as the server's rating (five hearts also stars the song, fewer takes the star away) when the server answers, and waited for until then; ratings and stars changed on the server reach the Q2's hearts at the next check. A star on the server newer than the change on the Q2 wins.
- Turning Show in Library off takes the server's songs and their covers out of the Library (the app keeps its own list, so turning it on again needs no new first copy). **Sign Out** removes both.

## Sync rules

- An artist includes albums added to the server later. A playlist follows the server, order and duplicates included. A song reached through several items is stored once.
- Songs land at `Subsonic/<Album Artist>/<Year> - <Album>/<Disc>-<Track> - <Title>.<ext>`, and each playlist as `_explaylist_data/<name>.m3u`, its name cut to the 63 bytes the Q2 keeps. An older version wrote longer names, and the Q2 added another copy of such a playlist at each sync: the next sync moves the file to a name that fits, but the copies already on the Q2 stay until you delete them.
- Deletions happen only after the downloads have finished, and only for what the sync put there.
- With Sync Entire Library on, the songs the check found are kept in `.subsonic/library.json` and used again, for up to a day, while the server reports the same last scan and song count (Navidrome does; other servers, and a library of more than 20,000 songs, are checked in full each time). Playlists are checked every time. **Check Again**, on the page a finished sync leaves, checks everything.

## What it touches

Only `Subsonic/`, the playlist `.m3u` files it wrote and `.subsonic/`, Settings > Storage's sizes included. An older `Navidrome/` folder is moved to `Subsonic/` once, at start-up. Nothing else on the card is read or changed.

## Library and firmware extensions

Newer Q2 Pod firmware offers extensions to card apps. Without them everything still works, a little less smoothly:

| Extension | With it | Without it |
|---|---|---|
| `library` | After a sync the Q2 updates its library and imports the playlists itself (it waits while music is playing). A playlist you made on the Q2 is never replaced: a server playlist with the same name arrives as "<name> (Subsonic)". | Run **Library → Update Local Music**, then **Playlists → Import playlist** yourself. The sync page's **Update Your Library** row reminds you. |
| `progress` | A real progress bar. | A text bar such as `[#####-----] 47 %`. |
| `playlist` | Streaming plays the synced songs from the card inside a playlist, streams every format the Q2 plays as it is, and keeps streamed songs in the Stream Cache. | Everything in the list streams, synced or not, only FLAC and MP3 stream as they are (others as MP3 320), and streamed files are deleted as you go. |
| `catalogue` | **Show in Library**: the server's songs and playlists in the Q2's Library. | No Show in Library row; the app writes none of its files. |
| `ratings` | Hearts follow a song between the Q2 and the server. | Hearts stay on the Q2. |
| `libsource` | Show in Library follows the Library's **Streaming Songs** switch: it is On only while the switch is, turning it on turns the switch on (the Q2 asks first), and the app pauses while the switch is off. | Show in Library is On or Off by its own setting, whatever the Library shows. |
| `artist` | An artist's page says its albums, singles, songs and genre, and has Singles & EPs, Similar Artists and All Songs; songs show their album and length. | The artist's page has Play, Shuffle, Radio, Top Songs and its releases. |
| `album` | An album's page has Shuffle beside Play, says its artist, year, song count and running time, and shows each song's length. | The album's page has Play and its songs. |
| `radio` | Now Playing's **Radio** on a song from your server starts an endless radio of songs like it (`getSimilarSongs2` with the song), the song playing on where it is: more are added when about 10 are left, never a song played or queued lately (the last 200), and the blue **Radio** pill lights while it plays; tap it to stop. An artist's Radio is endless too. The car remote can start one as well. | Now Playing's Radio doesn't start one; an artist's Radio is still endless. |
| `signin` | **Sign In from Your Phone** opens the QR page in one press, the Q2 follows the phone's steps (**Continue on Your Phone**, **Signing In…**, **Signed In** or why it failed) on a page of its own, and the sign-in page stops when you leave the QR page. | Press the row a second time to open the QR page, which shows the outcome beside the code; the sign-in page stops after a pause in the page's refreshes once the QR page is left. |
| `playlists` | With Show in Library, a server playlist you change on the Q2 (songs added or removed, a new name, deleted) is changed on the server too, and its server cover shows on its row in Playlists. | A playlist changed on the Q2 is put back as the server has it at the next sync; no cover on the row. |
| `storage` | **System settings → Storage** shows the card space taken by Downloads (`Subsonic/`) and the Stream Cache (`.subsonic/`), lists each item you sync with its size (press to open it, hold Play/Pause to take it out of Sync), and sets a Downloads **Limit** that a sync can't go past. | The app writes no storage files and there is no Downloads limit. |
| `ahead` | The Q2's **Streaming → Configuration → Download Ahead** (Off, 1, 2 or 3 songs) sets how many songs the app downloads ahead, in the Q2's play order (shuffle and Up Next included), and Now Playing shows how far a loading song has downloaded. | The app downloads the next two songs of the list. |
| `grow` | A streamed song starts once a few seconds of it are on the card, rather than once all of it is (on a Q2 Muse whose player plays a song as it arrives). | A streamed song starts once it is whole. |

## Errors and logs

A failure shows a short message on screen. Open its **Details** row for the operation, the HTTP status or Subsonic error code, and the time. The full trail is in `.subsonic/log.txt` (the older part in `log.txt.1`); the user name, password, tokens and API key a request signs in with are never logged, and at start the app takes out any that an older version left there. An internal error while one page is answered shows "Something went wrong" with **Retry**, and its trace goes there too; a sync or stream carries on. If the app crashed, its trace and exit code are added there at the next start. **Settings** shows the app's version, for a bug report.

## Update and remove

**System settings → App Store** shows **Update** when a newer release is out. By hand, replace the five files in `.subsonic` listed above. Your login, settings and selection are kept.

To remove it, press **Subsonic** twice in **System settings → App Store**. On Q2 Pod 1.5.9 or later that deletes all of `.subsonic/`: your login, settings, selection and sync records. On older Q2 Pod it leaves that folder, login included, so first **Settings → Account → Sign Out**, which deletes the stored login, and delete the folder afterwards to remove everything. Synced music stays in `Subsonic/`, and its playlists stay as `.m3u` files in `_explaylist_data/`, beside your other playlists. Delete `Subsonic/` and those playlist files to free the space and start clean: an install after a remove starts with no sync records, so it downloads your selection again and saves its playlists under new names beside the old ones.

## Build

    contrib/shanlingq2/build.sh

needs Go 1.21 or later (go.mod requires Go 1.27 and pins the toolchain, which an older `go` fetches on first use) and python3 (no dependencies outside Go's standard library), and leaves the card files in `target/shanlingq2/.subsonic` and the release ZIP beside them. More: [contrib/shanlingq2/README](contrib/shanlingq2/README).
